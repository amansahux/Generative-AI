🚀 Chapter 1.2: NLP (Natural Language Processing)

Definition:
AI ki field jo computers ko human language ko understand, process aur generate karna sikhati hai.

Examples:
• Translation
• Chatbots
• Sentiment Analysis
• Summarization
• Question Answering

Natural Language:
Hindi, English, Hinglish, etc.

Not Natural Language:
Java, Python, JavaScript

LLM is NOT NLP.
LLM is a modern technology built to perform NLP tasks.

🚀 chapter 1.5 :-  Context Window

Context Window
↓

Maximum number of tokens an LLM can process at one time.

Measured in:
Tokens ✅

Not:
Words ❌
Characters ❌

Context includes:
• System Prompt
• Chat History
• Current Prompt
• Retrieved Documents
• Tool Output
• Response Tokens
  
  🚀 Chapter 1.6: Hallucination

  Hallucination
↓

LLM generates confident but factually incorrect or unsupported information.

Reasons:
• Knowledge cutoff
• Less context
• Ambiguous prompt
• Missing relevant data

RAG reduces hallucinations by providing relevant context.

Hallucination ≠ Lying
