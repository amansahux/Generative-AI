7️⃣ Batch Processing

Ye chapter yaad hai?

Instead of

await model.invoke(a);

await model.invoke(b);

await model.invoke(c);

Use

await model.batch([
  a,
  b,
  c,
]);

Har provider me cost kam ho ye guarantee nahi hai, lekin request management better ho sakta hai aur throughput improve ho sakta hai.
