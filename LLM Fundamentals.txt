📚 Chapter 1 LLM FUNDAMENTALS :-
 
     🚀 Chapter 2.1: What is an LLM?
     An LLM (Large Language Model) is a deep learning model trained on massive amounts of text to understand and generate human-like language by predicting the next token.
     
      Massive text
      Deep Learning
      Next Token Prediction

     LLM = Large Language Model

Large
↓
Huge data + huge parameters

Language
↓
Human language and code

Model
↓
Trained AI system

LLM works by:

Prompt
↓

Next Token Prediction
↓

Completion

LLM does NOT search like Google.

It generates responses using learned patterns.

🚀 Chapter 2.3: Training vs Fine-Tuning vs Inference

Training
↓

Learning from massive datasets.

Parameters update.

Very expensive.

---------------------

Fine-Tuning
↓

Further training on a specific dataset.

Makes model specialized.

---------------------

Inference
↓

Using the trained model.

No learning.

No parameter updates.

Only next-token prediction.


                 Training
                    │
     Learn Everything from Massive Data
                    │
        ✅ Parameters Updated
                    │
                    ▼
              Base LLM Ready
                    │
                    ▼
             Fine-Tuning
                    │
     Learn One Specific Domain
                    │
        ✅ Parameters Updated
                    │
                    ▼
         Specialized LLM Ready
                    │
                    ▼
              Inference
                    │
      User Prompt → AI Response
                    │
        ❌ No Parameter Update

   🚀 Chapter: 2.5 Knowledge Cutoff


   Knowledge Cutoff

        ↓

Latest date until which the model was trained.

Inference does NOT update knowledge.

Latest information requires:

• Web Search
• APIs
• RAG

Knowledge Cutoff ≠ Context Window

Knowledge Cutoff = Training Time Limit

Context Window = Token Limit

   

 🚀 Chapter: 2.6 Function Calling (Concept)


  Function Calling

↓

LLM does NOT execute functions.

LLM only decides:

• Which function to call
• What arguments to pass

Backend:

↓

Executes the function

↓

Returns the result

↓

LLM converts result into natural language.

Examples:

• Weather API
• Gmail
• Database
• Payments
• Calendar
