Agar tum provider-agnostic pipeline bana rahe ho ya LCEL chains use kar rahe ho, JsonOutputParser bahut useful hai.



📖 LCEL (LangChain Expression Language)


Why LCEL Exists?

LangChain developers ne socha...

"Har component me invoke() hai."

PromptTemplate

↓

invoke()

Model

↓

invoke()

Parser

↓

invoke()

To fir manually invoke kyu kare?

Chain bana dete hain.





const prompt = await template.invoke(data);

const response = await model.invoke(prompt);

const result = await parser.invoke(response);
                  |
                  |
                  |
                  \/

const chain = template
    .pipe(model)
    .pipe(parser);

const result = await chain.invoke(data);

🤖 Chapter 10: Tools (The Beginning of AI Agents)
A Tool is any external capability that an LLM can use to perform an action or fetch information it doesn't inherently possess.



Important Concept

LLM Tool ko directly execute nahi karta.

Ye bahut important line hai.

LLM sirf decide karta hai

Mujhe weather tool use karna chahiye.

Execution tumhara application karta hai.
